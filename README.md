# Premium Dark Developer Portfolio

A Next.js App Router + TypeScript + Tailwind CSS starter for a premium, dark software developer portfolio.

## Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 3
- Framer Motion (subtle entrance/hover motion)
- Lucide React icons

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Customize first
1. Update `data/projects.ts` with verified project details and links.
2. Replace the placeholder email and social links in `components/SiteFooter.tsx` and `app/page.tsx`.
3. Add your real project screenshots under `public/projects/` and update each project's `image` field.
4. Review all metrics before publishing; remove any number you cannot substantiate.
5. Update metadata in `app/layout.tsx`.

## Notes
- The project preview panels are designed as visual placeholders, so the site looks polished before screenshots are added.
- Do not publish client-confidential screenshots, private repositories, or credentials.
- Keep the portfolio truthful: describe your role and contributions accurately.
